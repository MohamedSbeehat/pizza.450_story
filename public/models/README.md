# نماذج 3D (اختياري)

ضع هنا ملفات `.glb` لاستبدال العناصر المبنية بالكود، ثم فعّلها في `src/data/models.js`:

```js
oven: { url: '/models/oven.glb', scale: 1, position: [0, 0, 0], rotation: [0, 0, 0] },
```

العناصر القابلة للاستبدال: `oven`, `table`, `chair`, `lamp`, `counter`.
يُفضّل أن يكون الملف أقل من 2MB وبعدد مضلعات منخفض.
