# الصور

هذه الصور مولّدة بواسطة `npm run images` من المجلد `photo/` (انظر `scripts/images.config.mjs`).

- `brand/`  الشعار
- `people/` صور الأشخاص
- `story/`  صور المكان والفرن والواجهة

لإضافة صورة بسرعة بدون السكربت، انسخها هنا بالاسم الذي يستخدمه `src/data/story.js`
(مثلًا `story/pizza.webp`) — وستظهر في الموقع مباشرة.
